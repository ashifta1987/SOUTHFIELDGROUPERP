# Build specification

Save the owner's build document here as `SOUTHFIELD_ERP_SPEC.md`. To get it, open the document "Southfield ERP — Corrected Build Prompt" and download it as Markdown.

What the specification contains:

- **Parts A–J:** every field, rule and screen.
- **Part I:** the acceptance checks for each phase.
- **The Indian law appendix.**

The prompt in `docs/prompts/SOUTHFIELD_ERP_PROMPT.md` refers to it by section, so don't build a module until you have read its part of the specification.

If you add SOP documents (production, sales and distribution), put them in this folder as Markdown too. The help assistant reads them.
